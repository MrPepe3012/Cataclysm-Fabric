# Generated item textures

Built-in image generation; transparent sprites sampled directly to **16 × 16** using nearest-neighbor pixel selection. Existing model references consume the final files under `src/main/resources/assets/cataclysm/textures/item/`.

## Final prompt set

### elders_eye.png
Create a single Minecraft inventory item pixel-art sprite for Elder's Eye, a rare eldritch guardian eye relic in the Cataclysm resource pack. Square canvas, genuinely transparent background. One centered compact round ancient eye, muted dark brown stone/cracked ivory outer rim, pale turquoise pupil, restrained violet inner shadow, crisp chunky pixel clusters, no gradients or antialiasing, intended to downsample to 32x32. Object fills 85% canvas. No text, no border, no glow outside silhouette, no extra objects. Use case stylized-concept, production game item texture.

### Golem Head
Uses the actual vanilla entity head and texture through a special renderer. See head-and-wing-refinement.md.
